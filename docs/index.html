Express, MongoDB, Handlebars

NextStep is a job search and networking tracker built to help users manage applications, save professional contacts, record networking interactions, and keep follow-up tasks organized. I built it around a real workflow problem: keeping a search process structured without making it cumbersome.

Pitchdeck

JavaScript, Flask, MongoDB

Pitchdeck is a job discovery platform that scrapes listings, organizes them into useful categories, and recommends roles based on user preferences. The main challenge was turning raw job data into something ranked and readable rather than simply displaying a feed.

React, Express, Node, MongoDB

Cache is an online catalog system for physical media built for WNYU. It includes search, favoriting, account features, and a browsing experience designed to make a catalog feel less like a database and more like a place you would actually want to spend time in.
